# Contributing

Issues and pull requests are welcome.

- For a large change (a new backend, what the agent may edit, the default prompt), open an issue first.
- A pull request needs tests for what it changes and must pass CI; with `backend="keep"` a wrapped run must still
  match the plain run.
- Maintainers may push small fixes to your branch before merging; your commits keep your name.
- Contributions are released under this repository's MIT license.
